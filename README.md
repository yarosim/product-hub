# Product Hub

Central, shareable product page for digital offers + curated Pinehurst lifestyle cross-sell.

**Live URL (enable Pages if not already):**  
https://yarosim.github.io/product-hub/

## Purpose

- One short link for YouTube / Shorts / TikTok descriptions
- Cross-sell digital products across channels
- Surface Pinehurst official shop picks for lifestyle / family content
- Monetization: Stripe for digital, official (or later affiliate) for physical

## Enable GitHub Pages

1. Repo → Settings → Pages
2. Source: Deploy from a branch
3. Branch: `main` / root → Save

## Update products

Edit `products.js`. Keep channel names short. Use Stripe Payment Links or landing pages.
